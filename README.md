# Conversion Calculators

Conversion calculators from [CalciHub](https://calcihub.com/) for converting measurements between commonly used units and systems.

This repository documents the conversion calculator collection available on CalciHub.

The Conversion collection currently includes **15 calculators** covering:

- Length
- Weight and mass
- Temperature
- Volume
- Area
- Speed
- Energy
- Power
- Pressure
- Data storage
- Cooking measurements
- Fuel efficiency
- Angles
- Number bases

## Calculation methodology

Conversion results are based on defined conversion factors or mathematical relationships between units.

Where relevant, calculator documentation explains:

- The units involved
- The conversion factor or formula
- Input and output units
- Rounding or precision considerations
- Relevant assumptions
